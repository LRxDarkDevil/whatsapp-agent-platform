# Changelog

## 0.1.0 - 2026-10-05

Initial community release:

- MCP v2 / 2026-07-28 server architecture.
- Local stdio transport.
- Self-hosted Streamable HTTP transport.
- Static bearer protection for private hosted deployments.
- Host/Origin validation and non-loopback safety checks.
- WhatsApp Agent Platform status, update, send-text, read/typing, media-send, and media-metadata tools.
- Optional file upload/download tools restricted to a configured root.
- Agent Platform capabilities MCP resource.
- Protocol-level MCP tests using the official TypeScript client SDK.
