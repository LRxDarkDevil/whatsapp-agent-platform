# Changelog

All notable changes to this project will be documented here.

## 0.1.0 - 2026-10-05

Initial community SDK release for WhatsApp Agent Platform v1:

- Typed long-poll updates with exact signed-int64 cursor preservation.
- Creator discovery from retained Agent Platform updates.
- Text, image, video, audio, document, and sticker sends.
- Quoted replies.
- Read receipts and typing indicator.
- Media upload, metadata, download, and deletion.
- Typed API/transport/validation errors.
- Safe retry behavior for ambiguous sends.
- Built-in per-method rate limiting and documented platform caps.
- ESM + CommonJS builds and TypeScript declarations.
